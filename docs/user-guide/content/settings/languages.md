# Languages

This is a running list of all languages that are used in the [Equivalents](../../content/add-multi-language-support-with-equivalents) feature.

{{< img src="images/languages-list.png" alt="The list of available languages in Content Controller" >}}

## Add a new language

1. Click **Add**
2. Give the language an IETF Language Tag, English Display Name, and Localized Display Name
3. Click **Add Equivalent Language**
