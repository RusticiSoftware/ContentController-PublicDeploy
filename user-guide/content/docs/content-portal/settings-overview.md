# Settings overview

## Overview

A Content Portal is set per Account in Content Controller. Each Account may have one portal, which then mirrors that accounts content page layout. External users may be granted access to chosen portals.&#x20;

### General Settings

Here are all the current options available for an Account's Content Portal. After making any changes you must hit **Save** for them to update.

* **Portal URL**: This is the portal link to share with external users whom you have granted access to.
  * Note that the refresh icon indicates a way to "regenerate" the URL. Clicking this will provide this portal with a new URL and make the previous one unreachable.
  * Note the clipboard icon, clicking this will copy the portal's URL.
* **Portal Name**: Give the portal a name, this will appear at the top of the page.
* **Portal Message**: Display a custom message at the top of the portal page, this is optional.
* **Standards**: Choose which download (dispatch) options will appear for the external users. At least one must be chosen in order to get content out of the portal.&#x20;
* **Display** **Licensing**: Depending on how that particular account's licensing is setup, appropriate information will be displayed in the portal. This is off by default.&#x20;
* **Display** **Tags**: To better help with content discoverability Tags may be enabled. This will display whatever tags are currently associated with a given piece of content. This is off by default.
* **Activation**: This is where you may turn an Account's Content Portal on or off. Checking it and hitting save will turn it on, the reverse of unchecking and saving will turn it off - preventing anyone was logging into it.

### Appearance&#x20;

Under the Appearance tab will be the available Display Settings. After making any changes you must hit **Save** for them to update.

* **Sign-In Box Header Color**: This will adjust the color of the header within the sign-in box.
* **Sign-In Page Background Color**: This will adjust the sign-in page background color.
* **Portal Header Color**: This will adjust the color of the header in the portal itself. This is after a user would login.
* **Portal Header Settings Box Color**: This will adjust the portal dropdown gear box in the upper right corner.
* **Logo**: Uploading a logo will appear on **both** the sign-in and portal pages.

{% hint style="warning" %}
The logo must be **jpg**, **gif,** **png** or **svg** and must not exceed **250x150 px**.
{% endhint %}
