# Using a Content Portal

### Accessing a portal

Once a portal has been enabled for an account and at least one user has been granted access. It may then be used for sharing (dispatching) out content. Here is how those external users would login:

1. Navigate to the Content Portal's URL.
   1. This may be obtained from the Content Portal's **General Settings** page which may be found here [Broken link](broken-reference "mention"). Click on the clipboard icon next to the URL field to copy.
2. Here the approved user must enter their email to receive a one time code.
   1.

       <figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>
3. Assuming the user was added for this portal they will then receive an email that looks like this
   1.

       <figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>
   2.

       <figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure>
4. Copy and paste or type the code into the input box and click **Sign-In**. <mark style="background-color:yellow;">Note that this code will only last 5 minutes.</mark>
   1.

       <figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
5. You will now be logged into that specific Account's Content Portal.

<figure><img src="../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

### Downloading (dispatching) content

To download (dispatch) content. Simply follow these steps:

1. Select or multi-select the checkbox(s) next to each piece of content you need to obtain
2. Chose the standard from the dropdown menu
3. Click **Download**

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

From here the external user may upload to their system of choice as normal.

### Other things to know

Some additional items of note.

* The blue dot that appears on the listing page will indicate that something is new since the last time that user has logged in
* Clicking on a course will expand to show additional details
  * If enabled license information will appear here as well if setup by content
* If Limit by Account license is in place and enabled it will appear at the top of the portal page
