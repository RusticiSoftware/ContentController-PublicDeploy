# Languages

This is a running list of all languages that are used in the [Equivalents](../content/add-multi-language-support-with-equivalents.md) feature.&#x20;

![](../.gitbook/assets/CC-Languages.png)

### Add a new language

1. Click **Add**
2. Give the language an IETF Language Tag, English Display Name, and Localized Display Name
3. Click **Add Equivalent Language**
