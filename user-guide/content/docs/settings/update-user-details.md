# Update your user details

## Updating your user details

If at any point you need to change the display name, email address or password specifically for yourself. You can do so by:&#x20;

1. Clicking on the **gear** icon in the top right of your Content Controller account.
2. Click **Account**

Here, you can make the desired changes to your user account.&#x20;
